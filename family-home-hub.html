权限分离：
视频通话权限 ≠ 看护摄像头权限 ≠ 远程维护权限

电视节点 → 手机

爷爷奶奶可以按实体键或说“联系 Simon”，系统直接呼叫你的手机；也可以呼叫梦雨、爸爸、妈妈。

手机 → 电视节点

你或家人可以直接呼叫“父母家客厅”或“爷爷奶奶家”，把电视作为固定家庭视频终端。

家庭呼叫

高级版可以把“联系孩子们”设成同时呼叫多个授权成员，谁先接谁接，适合高龄老人。

智能音箱 = 语音入口

实体按钮保留作最可靠的兜底；语音负责更自然的日常使用。

老人只需要说自然语言

“给 Simon 打电话。”
“给梦雨打电话。”
“播放 Simon 发来的视频。”
“播放音乐。”
“声音大一点。”

语音背后发生什么

智能音箱 → 家庭中控 → Mini PC / 电视 / 通话系统

触发电视开机与切 HDMI
启动指定联系人的视频呼叫
控制音乐、音量和内容播放
未来可扩展家庭提醒、天气、留言
不要取消实体按钮。 老人口音、方言和环境噪音都可能导致语音识别失败；物理按键是必须保留的可靠入口。

采购原则：先只做父母家 Prototype。稳定 2–4 周后，再复制爷爷奶奶家。不要一次性买两套未经验证的会议设备和 CEC 配件。

老人端：尽量只有两种操作

方式 1：按一下

绿色实体键写着“给 Simon 打电话”。按下后：电视自动亮 → 切到 Mini PC → 自动呼叫 → 全屏视频。

方式 2：说一句

“给 Simon 打电话。” 或 “播放 Simon 发来的视频。” 其他后台流程全部隐藏。

核心验收标准：如果老人还需要找电视遥控器、选择 HDMI、登录 App、输入会议号或处理更新弹窗，就说明系统还没有做完。

实施路线

阶段内容验收标准
Phase 0确认两台电视品牌/型号、HDMI-CEC 能力、Wi‑Fi 条件。知道能否自动开机/切源，决定是否需要 IR。
Phase 1父母家桌面 Prototype：Mini PC + 通话相机 + 远程桌面。异地可以维护；重启后自动恢复。
Phase 2实体按钮 + 电视自动化 + 独立 PTZ。老人只按一次就能发起视频。
Phase 3加入智能音箱，把“联系人”映射为语音命令。“给 Simon 打电话”可稳定触发。
Phase 4把爸妈、梦雨等家庭成员手机加入通信层。手机 ↔ 两个电视节点可直接互联。
Phase 5内容推送、相册、家庭广播、家庭呼叫。Simon 可选择目标家庭节点远程推送内容。
Phase 6复制爷爷奶奶家第二套。第二套只改节点名和账号，不重新设计。

软件层的原则

通话

最终选型要以“一键/语音能否稳定发起指定联系人”为第一标准，而不是单看某个视频 App 是否流行。

中控

Home Assistant 可作为自动化中枢；Mini PC 负责大屏和本地控制；远程维护可通过安全的私网工具完成。

权限

能打视频 ≠ 能看 PTZ ≠ 能远程控制主机。 家庭成员权限应分开授权，尤其看护摄像头。
