# tsongshi.github.io

公开展示区（面向朋友分享的小作品），静态 HTML，GitHub Pages 托管。

## 用途

- 只放主动选择要展示给他人看的内容
- 不含任何工作/客户相关信息，不含真实姓名以外的身份信息
- `index.html` 为首页，后续作品可放子目录，如 `/fakao/xxx.html`

## 发布方式

在 Cowork 里说"发布这个 HTML 到公开展示区"，会被提交到本仓库并推送，几十秒内 https://tsongshi.github.io/ 生效。

## 备案通过后

`tsongshi.cn` 域名可通过 CNAME 指向本 Pages 站点（或迁移到腾讯云对象存储静态托管，二选一，见项目 `技术方案-V1.md`）。
